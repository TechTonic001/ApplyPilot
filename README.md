# ApplyPilot

ApplyPilot is organized as a monorepo with separate client and server workspaces.

## Project structure

- `client/` — React application built with Vite and Tailwind CSS.
- `server/` — Node.js API built with Express and Mongoose for MongoDB.
- `.github/copilot-instructions.md` — project rules for future contributions and suggestions.

Firebase Authentication is used for identity. See each workspace's `.env.example` for the environment variables expected as the application is implemented.

No application code or dependencies have been added yet.
